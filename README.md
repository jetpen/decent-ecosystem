# Decentralized Ecosystem

This document repository serves to provide the vision around the
decentralized ecosystem for securing the free and open Internet into
the future.

## Goals

### Self-Sovereign Identity (SSI)

End users have self-sovereign digital identity. It is a Bitcoin-like
experience for identity in the form of generating and holding your own
keys.

### Authentication

End users own a wallet for holding their keys to sign things using
their self-soverign digital identity. This begins with signing
authentication challenges for logging into participating web sites.

### Multi-Factor Authentication (MFA)

Multisig serves the purpose of multi-factor authentication.

### Web site participation in Single Sign-On (SSO)

Provide the components for web sites to integrate into the
decentralized p2p network for a identity and data registry, so that
users have SSO universally across participating web sites with no
central authority. That would be an attractive proposition.

The entry point for this technology should target Self-hosted Web
sites. The most reachable target is Apache HTTP Server running
WordPress. About 40.3% of all web sites run WordPress, according to
[W3Techs as of 12 September
2026](https://w3techs.com/technologies/details/cm-wordpress).

### Web browser and authenticator experience

Preserve the familiar web browser experience for the end user, except
augment the authentication capabilities associated with passkey in
combination with a wallet application to manage private keys. 

### Data sovereignty for censorship-resistance

With the adoption of SSI by web sites and applications (desktop and
mobile) with back-end services in the cloud, users gain sovereignty
over their account information, their data, and their social
network. WIth ownership over their own data replicated over diverse
infrastructures, users cannot be entirely rug-pulled, censored, or
cancelled. With applications and services either self-hosted or
distributed over diverse providers, users become resilient to
rug-pulling, censorship, and cancellation of application
capabilities. Similarly, web sites that participate in the
decentralized ecosystem become more resilient themselves.
